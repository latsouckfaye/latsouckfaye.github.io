# Backlog d'articles

Fichier de suivi personnel — jamais rendu sur le site (dossier/fichier préfixé `_`,
exclu du rendu Quarto). Sert uniquement à ne pas perdre les idées.

Catégories valides : `Data & Tech` · `Finance & Investissement` · `Projets & Build`

Statuts : `Idea` (pas encore de fichier) → `Draft` (dossier créé, `draft: true` dans le
.qmd) → `Published` (`draft: false`).

Pour passer une idée en Draft : dupliquer `blog/_template/` vers `blog/<slug-de-larticle>/`,
renommer le fichier `.qmd`, remplir le front-matter, écrire. Pour publier : passer
`draft: false`.
